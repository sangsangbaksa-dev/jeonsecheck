# jeonsecheck · 전세 보증금 안전 점검

전세·반전세 보증금이 **깡통전세**가 될 위험을 숫자로 점검하는 정적 웹앱입니다.
위험비율, 시세 하락 시나리오, 경매 시 노출 금액, 계약 단계별 점검표, 날짜 계산(.ics), 특약 문구 참고 예시를 한곳에서 씁니다.

> **주의:** 이 앱의 계산은 입력값에 기반한 **참고용 추정치**입니다. 보장된 안전을 의미하지 않으며, 법률·세무·재무 자문이 아닙니다.

## 주요 기능

1. **물건 카드**: 이름, 주소 메모(선택), 주택 유형(아파트·빌라·다세대·오피스텔·단독·다가구), 계약 형태(전세·반전세). 금액은 원 단위 정수만 받습니다.
1-1. **등기부 요약**: 을구 근저당을 건별로 적으면 합계가 위험비율 분자가 됩니다(최대 10건). 압류·가압류 건수와 임차권등기 여부는 계산에 넣지 않고 경고로만 보여 줍니다.
2-1. **안전 구간 보증금 상한**: 위험 분석 탭에서 현재 시세와 10% 하락 가정 각각에 대해, 위험비율 70% 이하를 맞추는 보증금 상한과 줄여야 할 금액을 보여줍니다. 분석과 같은 정수 식을 씁니다. 함수: `safeDepositCeiling` (logic.js). 70%는 앱 자체 기준이며 **확인 필요**입니다.
2. **위험 분석**: 위험비율, 등급, 시세 10%·20% 하락 시나리오, 경매 낙찰가율 가정에 따른 노출 금액, 공시가격 140% 참고 판정. 각 숫자의 계산식과 근거(입력값·계산 규칙·가정·참고 기준)를 "숫자 읽는 법"에서 풀어 씁니다.
3. **점검표**: 계약 전 / 계약 시 / 잔금·입주 / 거주 중 / 퇴거 5단계. 체크 상태는 물건마다 저장됩니다. 인쇄용 시트(☐/☑)로 출력할 수 있으며 주소 메모와 메모는 넣지 않습니다.
4. **특약 문구 라이브러리**: 11개 참고 예시. 개별 복사, 여러 개 선택 후 번호 붙여 한 번에 복사. 법률 자문이 아님을 화면에 표시합니다.
5. **날짜·일정**: 계약일·잔금일·만기일로 계약갱신요구 기간, 대항력 발생일, 반환 요구 시점, 임차권등기명령 검토 시점을 계산합니다. 오늘 이후 다음 일정, 일정별 D-day와 알림일(지남·오늘·예정)을 보여 주고, 1·7·30일 전 알림이 든 `.ics` 파일로 내려받습니다.
6. **비교**: 최대 5개 물건을 같은 가정으로 나란히 비교합니다. 위험비율이 가장 낮은 물건을 "참고"로 강조합니다(동률이면 경매 노출액 기준). 안전하다는 판정이 아닙니다.
7. **설정·백업**: 낙찰가율·공시가격 비율 설정, JSON 백업과 복원, 요약 CSV 내보내기, 데이터 삭제.
8. **AI 설명 (선택)**: 자세한 내용은 아래 "AI 설명" 절을 보세요.

## 계산 규칙

모든 기준값은 `logic.js`의 `CONSTANTS` 객체 한 곳에 있고, 화면에 "확인 필요 · 기준일 2026-11" 라벨과 함께 표시됩니다. 법령과 시장 관행이 바뀌면 이 객체만 고치면 됩니다.

### 위험비율

```
위험비율 = (선순위 근저당 채권최고액 합계 + 선순위 임차보증금 합계 + 내 보증금) ÷ 예상 매매 시세
```

- 시세가 0원이면 계산하지 않고 "계산 불가"로 표시합니다 (0으로 나누지 않음).
- 시세보다 청구 합계가 크면 100%를 넘고 "매우 위험"입니다.
- 구간 판정은 정수 연산(BigInt)으로 합니다. 정확히 70%는 "안전", 80%는 "주의", 90%는 "위험"입니다.

| 위험비율 | 등급 | 출처 |
|---|---|---|
| 70% 이하 | 안전 | 앱 자체 기준 (확인 필요) |
| 70% 초과 ~ 80% 이하 | 주의 | 앱 자체 기준 (확인 필요) |
| 80% 초과 ~ 90% 이하 | 위험 | 앱 자체 기준 (확인 필요) |
| 90% 초과 | 매우 위험 | 앱 자체 기준 (확인 필요) |

구간 값은 법정 기준이 아니라 이 앱이 쓰는 참고 구간입니다.

### 시세 하락 시나리오

시세를 10%, 20% 낮춘 가상 시세로 같은 식을 다시 계산합니다. 하락율은 `scenarioDropPcts`에 있습니다.

### 경매 노출 (낙찰가율 가정)

```
낙찰가 = 시세 × 낙찰가율 (기본 80%)
배당 가능액 = max(0, 낙찰가 - 선순위 근저당 - 선순위 임차보증금)
노출 금액 = 내 보증금 - min(내 보증금, 배당 가능액)
```

- 낙찰가율 80%는 **가정값**입니다. 실제 낙찰가율은 지역과 물건에 따라 크게 다르며, 설정 탭에서 1~100%로 바꿀 수 있습니다.
- 근저당 채권최고액은 실제 대출잔액의 상한입니다. 경매비용, 최우선변제 소액보증금, 선순위 임차인의 대항 요건 순서는 **반영하지 않은 단순 모델**입니다.

### 공시가격 140% 참고 판정

```
청구 합계 ≤ 공시가격 × 140%  →  "보증보험 가입 가능성이 상대적으로 있을 수 있음 (참고)"
```

- 이 판정은 보증보험 가입 가능 여부를 알려주지 않습니다. 실제 가입 기준은 HUG·SGI 등 가입 기관에 확인해야 합니다. 설정 탭에서 비율을 50~300%로 바꿀 수 있습니다.
- 공시가격을 입력하지 않으면 "미입력"으로 표시합니다.

### 날짜 계산

| 항목 | 계산 | 상태 |
|---|---|---|
| 계약갱신요구 가능 기간 | 만기 6개월 전 ~ 2개월 전 (주택임대차보호법 제6조의3) | 확인 필요 |
| 대항력 발생일 | 전입신고 다음 날 0시 (주택임대차보호법 제3조 제1항) | 확인 필요 |
| 보증금 반환 요구 시점 | 만기일 이후 | 기준 안내 |
| 임차권등기명령 검토 시점 | 만기 후 보증금 미반환 시 | 확인 필요 |
| 만기 미입력 시 | 계약일 + 24개월 (추정, 화면에 "추정" 표시) | 추정 |

- 월 단위 이동은 말일로 보정합니다. 예: 1/31 + 1개월 = 2/28(평년) 또는 2/29(윤년), 2028-02-29 − 6개월 = 2027-08-29.
- `.ics` 파일은 종일 일정이며, 하루 전 알림(VALARM)을 넣습니다. 줄 길이는 75옥텟 기준으로 접습니다.

## 실행 방법

빌드 과정이 없습니다. ES 모듈을 쓰므로 `file://`로 열면 안 되고 로컬 서버가 필요합니다.

```bash
cd jeonsecheck
python3 -m http.server 8111
# 브라우저에서 http://localhost:8111 열기
```

또는 `npm start`(같은 명령)를 쓰세요. 포트 범위는 8111~8119입니다.

## 테스트

```bash
npm test
# = node --test tests/logic.test.js tests/ai.test.js tests/features.test.js
```

- `tests/logic.test.js`: 위험비율 edge case(시세 0, 시세 < 보증금), 구간 경계(70·80·90% 정확히와 1원 차이), 하락 시나리오 정수 경계, 경매 노출, 공시가격 140% 경계, 날짜 산술(월말, 윤년, 연도 경계), 계약갱신 기간, ICS 이스케이프와 줄 접기, CSV 수식 주입 방지, 입력 검증, 점검표 저장(물건별, 불변 토글, 새로고침 후 유지), 백업 왕복과 손상 데이터 처리.
- `tests/features.test.js`: 등기부 요약 검증과 경고, 일정 상태·알림일·ICS 알림 선행 일수, 특약 선택 복사, 비교 순위(BigInt 교차곱 비교, 동률 규칙), 인쇄 모델(메모 제외), 숫자 설명 항목과 확인 필요 표시.
- `tests/ai.test.js`: 전송 데이터에 주소·이름·메모·전화번호가 없는지, 키 형식, 응답 파싱, 규칙 기반 설명, fetch를 주입한 API 호출(네트워크 없음).

브라우저 검증은 Playwright로 390×844와 1280×800, 라이트·다크에서 콘솔 오류, 외부 요청, 가로 넘침을 확인했습니다. 점검 스크립트는 `_shots/`(git 제외)에 있습니다.

## 데이터와 개인정보

- 모든 데이터는 이 브라우저의 `localStorage`(키: `jeonsecheck-v1`)에만 저장됩니다. 서버로 보내지 않습니다.
- 저장소 접근이 막혀 있으면 데이터가 남지 않는다는 안내를 보여 주고, 앱은 기본 상태로 동작합니다.
- 백업 파일(JSON)에는 **AI 키가 들어가지 않습니다.** 백업 파일 자체는 민감한 금액 정보가 들어 있으니 안전한 곳에 보관하세요.
- 외부 스크립트, CDN, 웹폰트는 쓰지 않습니다. 시스템 글꼴만 사용합니다.

## AI 설명 (선택)

위험 분석 탭 하단의 "AI로 쉽게 설명 받기"입니다.

- **전송되는 데이터**: 주택 유형, 계약 형태, 예상 시세, 내 보증금, 선순위 근저당 합계, 선순위 임차 합계, 위험비율, 등급, 하락 시나리오 등급, 경매 노출 금액. 화면에서 전송될 JSON을 미리 보여 줍니다.
- **전송되지 않는 데이터**: 물건 이름, 주소 메모, 메모, 그 밖의 텍스트. 테스트가 이를 확인합니다.
- **호출 시점**: 버튼을 눌렀을 때만 호출합니다. 자동 호출은 없습니다.
- **호출 대상**: `https://api.anthropic.com/v1/messages`, 모델 `claude-haiku-5-5`, `max_tokens` 600. 헤더는 `x-api-key`, `anthropic-version: 2023-06-01`, `anthropic-dangerous-direct-browser-access: true`.
- **키 저장**: 사용자가 입력한 키는 `localStorage`의 `jeonsecheck-ai-key`에 저장됩니다. **브라우저 개발자도구에서 보이므로** 공용 컴퓨터에서는 저장하지 마세요. 키 삭제 버튼이 있습니다.
- **키가 없을 때**: 같은 레이아웃으로 규칙 기반 설명과 질문 3개를 보여 줍니다. AI가 아니라는 표시가 붙습니다.
- **응답 처리**: 응답은 JSON으로 검증합니다. 형식이 맞지 않으면 규칙 기반 설명으로 대체합니다. 응답 텍스트는 `textContent`로만 넣습니다.

## 수익화 메모 (구현하지 않음)

결제는 구현하지 않았습니다. 아래는 나중에 검토할 제안입니다.

- **무료**: 물건 3개까지 위험 분석, 기본 점검표, 특약 문구, 일정 `.ics` 1회.
- **유료 제안**: 일회성 4,900원(또는 월 2,900원 구독). 물건 무제한, 비교 5개, CSV 내보내기, AI 설명 월 30회(사용자 키 사용 시 제한 없음).
- 가격과 구간은 시장 조사 전의 임의 제안입니다.

## 확인 필요 항목 (정직한 목록)

아래 값은 **검증하지 못했거나 바뀔 수 있는** 기준입니다. 배포 전 반드시 최신 출처를 확인하세요.

1. **위험비율 구간 70·80·90%**: 이 앱의 자체 기준입니다. 법정 기준이 아닙니다.
2. **경매 낙찰가율 80%**: 가정값입니다. 지역·물건별 편차가 큽니다.
3. **공시가격 140%**: 보증보험 참고용 값입니다. HUG·SGI의 실제 가입 기준은 확인하지 못했습니다.
4. **보증보험(HUG·SGI) 가입 기준 전반**: 기관과 시기에 따라 다르며, 이 앱은 가입 가능성을 판정하지 않습니다.
5. **계약갱신요구권 행사 기간(만기 6~2개월 전)**: 주택임대차보호법 제6조의3 기준으로 작성했으나 법 개정 여부를 확인하지 못했습니다.
6. **대항력 발생 시점(전입 다음 날 0시)**: 주택임대차보호법 제3조 제1항 기준입니다. 실제 적용 시점은 사안마다 다를 수 있습니다.
7. **임차권등기명령 검토 시점과 보증금 반환 순서**: 일반 안내이며 절차 세부는 확인하지 못했습니다.
8. **경매 노출 모델의 단순화**: 경매비용, 최우선변제 소액보증금, 선순위 임차인 대항 순서, 확정일자 효력 순서는 반영하지 않았습니다.
9. **특약 문구**: 참고 예시입니다. 실제 계약에 맞는지 전문가가 검토해야 합니다.
